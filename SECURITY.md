# Security Policy

## Scope

AIDCNet is currently an early UI simulation. It does not implement a live peer-to-peer network, real cryptography, identity management, AI threat detection, or secure message transport. Do not submit real secrets or sensitive data to this prototype.

## Reporting a vulnerability

Please do not publish exploit details in a public issue. Contact the repository owner through GitHub's private vulnerability reporting feature if it is enabled, or use GitHub's private contact channels. Include a concise impact summary, affected commit or file, and reproducible steps where safe.

## Security claims

Dashboard metrics and labels are illustrative only. A displayed status is not proof that a control is implemented or operating. Any future security protocol must have a documented threat model, reviewed design, tests for misuse and failure cases, and independent review before being described as production-ready.
